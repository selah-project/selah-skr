# تنخ — سرائیکی ترجمہ (selah-skr)

ایہ عبرانی پاک نوشتیاں (تنخ) دا سرائیکی ترجمہ ہے۔ ہر آیت اپݨی فائل
وِچ ہے، تے ہر token اپݨے عبرانی لفظ نال ٻنھیا ہویا ہے۔

**لکھت: شاہ مُکھی (فارسی-عربی اکھر)، سجّے توں کھٻے۔** ٻولی لکھی ہوئی
معیاری سرائیکی ہے — ملتان، بہاولپور تے ڈیرہ غازی خان دی کتابی ٻولی۔
سرائیکی دے اپݨے اکھر — **ٻ ڄ ݙ ڳ ݨ ݜ** — اکھر ہن، نشان نہ؛ کݙاہیں نہ
کٹے ویندے۔

## عبرانی — پہلے

ایہ ترجمہ ایں کیتے ہے جو توکوں عبرانی ول گھن ونڄے — عبرانی دی جاہ گھنݨ
کیتے نہ۔ جیہڑی شے ہمیشہ پڑھی ویندی ہے او عبرانی ہے: اوندے اکھر، اوندیاں
آوازاں، اوندے نشان۔ سرائیکی متن ہِک ٻاری ہے، بدل نہ۔ جتھاں ݙوہیں وکھرے
تھیوݨ، سچ عبرانی وِچ ہے۔

## فائلاں دی بݨتر

```
<کتاب>/<باب>/<آیت>.json
```

فولڈراں وِچ کتاباں دے ناں انگریزی وِچ لکھے ہوئے ہن: `genesis/1/1.json`،
`psalms/33/12.json`.

ہر فائل:

```json
{
  "translation": "پوری آیت ہِک واری پڑھی ویندی ہے",
  "tokens": [{"surface": "عبرانی لفظ", "gloss": "سرائیکی گلاس"}]
}
```

`surface` — **سطح**، عبرانی ریکارڈ۔ ایہ ساݙی لکھݨ دی شے نہ؛ ایہ نیہہ
توں آندی ہے تے وٹائی نہ ویندی۔

`gloss` — **گلاس**، اوں ہِکے عبرانی token دا سرائیکی معنیٰ۔ گلاساں دی
ڳݨتری عبرانی لفظاں دی ڳݨتری برابر ہے۔ ہر واری۔

`translation` — **ترجمہ**: پوری آیت اپݨی جاہ اُتے، ایں کیتے جو اُچی
پڑھی ونڄ سڳے۔ لفظاں دی ترتیب سرائیکی گرامر موجب ہے (فعل اخیر وِچ)، پر
`tokens` دی لڑی عبرانی ترتیب پکی پکڑیندی ہے۔

`marks` — صرف ⟨את⟩ دے token اُتے: او سرائیکی لفظ جیندے ول نشان اشارہ
کریندا ہے۔

## ⟨ ⟩ دا مطلب

کونے آلیاں بریکٹاں ݙو وکھریاں شیواں کیتے ورتیجدیاں ہن، تے انہاں کوں
وکھرا کرݨ ضروری ہے۔

**1 · ⟨את⟩ — عبرانی دا نشان، جیہڑا ترجمہ نہ تھیندا۔** عبرانی وِچ אֵת
ہِک نِکّا لفظ ہے جیہڑا اوں شے توں پہلے کھڑدا ہے جیندے اُتے فعل ٹُردا
ہے۔ سرائیکی وِچ ایندا برابر لفظ کائنی، تے ٻہوں سارے ترجمے ایں کوں
چُپ چاپ چھوڑ ݙیندے ہن۔ اساں ایں کوں رکھدے ہیں، جیویں لکھیا ہویا ہے —
ایہ عبرانی دی بݨتر دا حصہ ہے۔ ایہ چھپائی دی غلطی نہ؛ ایہ لفظ متن وِچ
ہے۔ نشان ہِک ٹبر ہے: את کدی کدی لاحقے نال آندا ہے (ואת، אתו، אתם،
מאת) — سبھ ہِکو ٹبر دے ہن۔

**2 · ⟨لفظ⟩ — او سرائیکی جیہڑا عبرانی وِچ کائنی۔** جتھاں سرائیکی جملہ
کھڑا تھیوݨ کیتے ہِک لفظ منگدا ہے جیہڑا عبرانی نہ لکھیا، او لفظ بریکٹاں
وِچ رکھیا ویندا ہے۔ بریکٹاں آہدیاں ہن: *ایہ لفظ ترجمہ کرݨ آلے دا
ودھایا ہویا ہے؛ عبرانی وِچ کائنی۔*

**بریکٹاں دے اندر کوئی اوپری ٻولی کائنی۔** یا سرائیکی ہے یا عبرانی دا
نشان ⟨את⟩ — تریجھی شے کائنی۔ او گلاس جیہڑا سارا ای بریکٹاں دے اندر
ہووے، غلطی ہے: ہر قطار دے پچھوں ہِک عبرانی لفظ کھڑا ہے۔ صرف نشان آپ
وکھرا ہے۔

## ناں

ناں **ترجمہ نہ تھیندا، حرف-نقل تھیندا ہے**۔

| عبرانی | اِتھاں | جو رد تھیا |
|---|---|---|
| יהוה | **یاہوہ** | خداوند · رب · ربّ · مالک · سائیں · خدا · اللہ · یہوواہ |
| אלהים | **ایلوہیم** | ناں دی جاہ اُتے خدا · اللہ · رب |
| אל · אלוה | **ایل** · **ایلوہ** | ناں دی جاہ اُتے خدا · معبود |
| אדני | **ادونای** | خداوند · آقا · مالک · سائیں |
| שדי | **شدّای** | **قادرِ مطلق** کلہا |
| יה · צבאות | **یاہ** · **تصواوت** | ربّ الافواج |

**خداوند اردو تے سرائیکی بائبل وِچ ٻہوں چِر توں کھڑا ہے، تے سائیں
سرائیکی دا اپݨا، مِٹھا لفظ ہے۔** پر ایہ اِتھاں کائنی۔ **خداوند** ہِک
لقب ہے، ناں نہ؛ **سائیں** تے **رب** وی لقب ہن؛ **یہوواہ** ہِک رلی ملی
صورت ہے۔ جتھاں متن יהוה آہدا ہے، ایہ سارے ناں کوں ڈھک ݙیندے ہن۔ ایندا
مطلب ایہ نہ جو ایہ مندے سرائیکی لفظ ہن — مطلب ایہ ہے جو او **ناں دی
جاہ اُتے** کھڑدے ہن، ناں آپ نہ۔ جیکر کوئی ریت ݙیکھݨ چاہوے، او ٻئیاں
سرائیکی ترجمیاں وِچ ملسی۔ اِتھاں جو لکھیا ہویا ہے اوہو کھڑا ہے۔

**حرفِ جار گرامر ہن۔** *یاہوہ دا*، *یاہوہ کوں*، *یاہوہ توں*، *یاہوہ
نال*، *یاہوہ کیتے* — ایہ سرائیکی گرامر ہے، ناں دا وٹاوݨ نہ۔ مُڈھ
ہمیشہ پورا رہندا ہے۔ جیہڑی شے حلال کائنی او مُڈھ ترٹاوݨ (*یہوہ*)،
مُڈھ دا اکھر وٹاوݨ (*یاہوا*، عربی ه نال *یاهوه*)، یا ناں نال کوئی
ریتی لقب جوڑݨ (*خداوند یاہوہ*) ہے۔ ناں نال ادبی وادھا — **تعالیٰ**،
**جلّ جلالہ** — وی کائنی؛ عبرانی وِچ کائنی، ساݙے کالم وِچ وی کائنی۔

## عام خدا تے عام مالک حلال ہن

جتھاں عبرانی قوماں دے معبوداں دی، یا کہیں انسانی مالک دی ڳالھ کریندی
ہے، اُتھاں *معبود*، *دیوتا*، *ٻئے خدا*، *مالک*، *سائیں* ٹھیک کھڑدے
ہن — ایہ ناں دا ڈھکݨ نہ، ترجمہ ہے۔ **فیصلہ عبرانی token کریندا ہے،
سرائیکی لفظ نہ۔** سارہ اَوراہام کوں «میݙا سائیں» آکھ سڳدی ہے، تے
اُتھاں ایہ ٹھیک ہے۔

## نشان لڳے لفظ

- **خیسِد** (חֶסֶד) — عہد آلا پیار جیہڑا نہ مُکدا۔ صرف «رحم» نہ، صرف
  «پیار» نہ، صرف «فضل» نہ۔ سرائیکی وِچ ہِک لفظ کائنی جیہڑا ایں کوں
  پورا چا سڳے۔
- **شیول** (שְׁאוֹל) — مُردیاں دی جاہ، جیویں عبرانی آہدی ہے۔ دوزخ نہ،
  جہنم نہ۔
- **ماشیاخ** (מָשִׁיחַ) — **مَسح تھیا ہویا** — تنخ دے درجے اُتے
  کݙاہیں «مسیح» نہ۔
- **تورات** (תּוֹרָה) — ہدایت، تعلیم۔ **ברית** — **عہد**۔ **שבת** —
  **شبّات**، ستواں ݙینہہ۔ **משכן** — **مسکن**۔ **נביא** — **نبی**
  (پیغمبر نہ، رسول نہ)۔
- **نفس، روح، کبود** (נפש، רוח، כבוד) اپݨی جاہ موجب ترجمہ تھیندے ہن
  (جان/ساہ؛ روح/ہوا؛ جلال/وزن) — ہِک پکے لفظ نال ٻنھے ہوئے نہ۔

بندیاں تے جاہیں دے ناں عبرانی صورت گھندے ہن: **اَوراہام**،
**یِتصخاق**، **یعقوو**، **موشے**، **اہرون**، **مِتصرایم**، **پرعوہ**،
**یہوشوع**، **شاؤل**، **داوِد**، **شلومو**، **یروشلایم**۔ **حضرت**
ورگے لقب ناں توں پہلے کائنی — عبرانی وِچ کائنی۔

## آیت اپݨی روشنی وِچ

ہر آیت اوہو آہدی ہے جو اپݨی جاہ اُتے آہدی ہے — اساں ایں کوں عبرانی دے
ایں ایمان توں پڑھدے ہیں جو ایلوہیم ہِک ہے (استثنا 6:4)۔ بعد دی تعلیم
پچھوں نہ کھِچی ویندی؛ کہاݨی دا اخیر اوندے مُنڈھ وِچ نہ پڑھیا ویندا۔
ترجمہ کرݨ آلا اوہو ݙیندا ہے جو لکھیا ہے — نہ ودھ، نہ گھٹ۔

عبرانی دے نال رکھ کے پڑھو۔ **ہݨ تئیں ایں کرسی کوں کہیں سرائیکی
